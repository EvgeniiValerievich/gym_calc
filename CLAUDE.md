# Калькулятор для зала

Простая консольная программа на Python: считает разминочные подходы, подсказывает
вес на следующую тренировку и хранит историю результатов в `history.csv`.

Запуск: `python gym.py`

## Правила работы

- **Я новичок в программировании.** Объясняй простыми словами, без жаргона.
  Если без термина не обойтись — коротко поясни, что он значит.
- **Всё общение — на русском языке.** Комментарии в коде тоже на русском.
- **Перед любыми изменениями показывай план**: какие файлы поменяешь, что именно
  и зачем. Начинай менять только после того, как я соглашусь.
- После изменений запусти программу и покажи, что всё работает.
- Не усложняй: код должен оставаться понятным новичку. Без сторонних библиотек,
  только стандартный Python.

## Устройство проекта

- `gym.py` — вся программа.
- `history.csv` — личная история тренировок. Создаётся автоматически и в Git не попадает
  (см. `.gitignore`).
